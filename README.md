# Neptune Pest Control: bed bug fumigation in Nairobi

One page. `index.html` is the page, so the repo address opens it directly. Plain HTML, CSS and JavaScript, no build step.

## Edit
- **Copy:** edit `index.html`.
- **Phone, WhatsApp, prices, discount:** `assets/js/config.js`.
- **Colours and layout:** `assets/css/style.css`.
- **Images:** see `IMAGES.md`. Save files with the exact names into `assets/img/`.
- **Link to the other service page:** paste its live address into `otherPage` in `assets/js/config.js`. Until then the link stays hidden.

## Publish with GitHub Pages
1. Create a public repo named `neptune-bed-bug-fumigation` and upload everything here, keeping the folder structure.
2. Settings, Pages, deploy from the `main` branch, `/ (root)`.
3. Your page: `https://<user>.github.io/neptune-bed-bug-fumigation/`

## Before launch
Test the calculator, the WhatsApp form and the call and WhatsApp buttons on a phone.
